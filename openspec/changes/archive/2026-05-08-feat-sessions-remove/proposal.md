## Why（背景）

用户当前可以打开和恢复会话，但无法移除过时或误创建的条目。随着会话列表增长，界面会越来越杂乱，查找活跃工作变得更困难。为了保持会话管理可用性，我们需要一个安全的删除流程。

## What Changes（变更内容）

- 在 Sessions 标签页中为会话项新增删除操作。
- 删除前必须进行两步确认，与应用内现有确认交互模式保持一致。
- 删除成功后，立即将该会话从列表中移除。
- 确保删除后的分页与加载状态保持稳定。
- 为删除操作提供清晰的成功与失败反馈。

## 能力范围（Capabilities）

### 新增能力（New Capabilities）
- `sessions-remove`：允许用户在 Sessions 标签页中删除会话记录，并强制二次确认，同时保证 UI 与状态正确更新。

### 修改能力（Modified Capabilities）
- 无。

## 影响范围（Impact）

- 影响的 UI：Sessions 列表项操作与确认交互流程。
- 影响的后端：会话管理命令/服务（按 `session_id` 或路径删除）。
- 影响的行为：删除后的列表刷新/分页，以及缺失路径或路径被锁定时的错误处理。
- 预计不涉及外部 API 或依赖变更。
